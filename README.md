A simple and lightweight Windows system monitor written in C++ using WinAPI. The project was created as a pet project for studying system programming.

## ✨ Features
- **CPU & RAM**: Visual load indicators.
- **Disk Info**: Monitoring free space on disk C.
- **Uptime**: The operating time of the system since startup.
- **Processes**: A list of active process IDs.
- **TUI**: Flicker-free color console interface.

## 🛠 Technologies
- **Language**: C++26
- **API**: Windows API (WinAPI)
- **Build**: CMake
- **Compiler**: MSVC

## 🚀 How to launch
1. Clone the repository.
2. Open the folder in VS Code.
3. Make sure that you have the `C++ Build Tools' installed.
4. Build the project using the CMake extension (F7).
5. Run `System_Monitor.exe `.
